# 主结果表

> 全部为 **test 集**（179 张 / 283 个实例），3 个随机种子（42 / 43 / 44）均值。
> **口径务必看清**：不同表的 NMS IoU 不同，不可跨表比较。

## 一、640 与 896 分辨率：注意力模块对照（NMS IoU 0.7）

| 模型 | 640 mAP@0.5 | 896 mAP@0.5 |
|---|---:|---:|
| YOLOv11s 基线 | 88.42 | 90.79 |
| + CBAM（BN 重标定，neck / sppf） | 90.05 | 90.12 |
| + TripletAttention（neck / sppf） | 89.00 | **91.19** |
| YOLO26s 基线 | — | 91.35 |

**读法**：
- 分辨率是主变量——基线从 640 到 896 提升 **+2.37 pt**；而任何注意力模块在 896 上的
  相对增益都不超过 **+0.40 pt**，且落在种子波动区间内。
- CBAM 在 896 上反而**低于**基线（90.12 < 90.79），无法宣称有效。

## 二、最终对外口径（NMS IoU 0.5）

| 指标 | 数值 |
|---|---|
| mAP@0.5 | **92.12%**（3 种子均值，区间 [91.97, 92.21]） |
| mAP@0.5:0.95 | 54.23% |
| Precision | 91.68% |
| Recall | 85.17% |

NMS IoU 0.5 是在 **val 集上独立选定**的，不是拿 test 调出来的。

## 三、run 名对照（便于回查原始实验）

| run 名 | 含义 |
|---|---|
| `wire_v11_640` | YOLOv11s 基线，640 |
| `wire_v11_640_neck` / `_backbone` / `_both` | CBAM 注入位置三臂，640 |
| `wire_v11_640_cbamfix` | CBAM 修复版（SA conv bias + 空间中心化），640 |
| `wire_v11_896` | YOLOv11s 基线，896 |
| `wire_v5_640` / `wire_v5_896` | YOLOv5s 对照，640 / 896 |
| `wire_v12_640` / `_cbam` | YOLOv12s 对照，640 |
| `nf_*_s42/s43/s44` | 噪声地板（3 种子） |
| `att_v11_<imgsz>_<att>_s<seed>` | 注意力臂补种子 |

命名规则：`nf_` = 地板，`att_` = 注意力臂，后缀 `_s<seed>` = 种子。

## 四、关键负面结论

| 结论 | 证据 |
|---|---|
| 注意力模块无稳定增益 | 种子区间重叠；640 与 896 方向不一致；CBAM 在 896 低于基线 |
| CBAM 近似恒等映射 | 空间注意力输出退化为逐通道常数，被后续 BN 严格吸收 |
| 数据存在跨 split 近似重复 | test 179 张中 48 张与 train 近重复，指标应理解为同场景泛化 |
| mAP@0.5 与 mAP@0.5:0.95 分化 | 92.12% vs 54.23%：找到不难，框准仍有差距 |
